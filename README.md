# A Caesar Cipher Hacker

A program can hack messages encrypted with the Caesar cipher.

## Description

This program hacks messages encrypted with the Caesar cipher. It utilizes the cryptographic technique of "brute-force attack." The program does not identify when it has found the correct key, but depends upon the user to read the output and identify which decryption produces the original translation.
